# **Краткое описание набора данных**

### **Предметная область**

Набор данных представляет собой синтетические данные о заказах в сфере электронной коммерции

### **Количество объектов**

Около 10 тыс. записей о заказах

### **Количество признаков**

В наборе данных представлены 16 признаков

### **Назначение основных признаков**

- OrderID — уникальный идентификатор заказа
- CustomerID — уникальный идентификатор пользователя
- OrderDate — дата оформления заказа
- CustomerAge — возраст покупателя
- Gender — пол покупателя
- City — город 
- Category — категория товара
- Product — товар
- Quantity — количество единиц товара в заказе
- UnitPrice — цена за одну единицу товара
- Discount — скидка, примененная к заказу
- PaymentMethod — метод платежа
- OrderStatus — статус заказа
- DeliveryDate — дата доставки
- Rating — оценка, которую поставил покупатель
- TotalAmount — итоговая сумма заказа

### **Целевое значение**

Отсутствует. Набор данных предназначен для практики очистки данных и исследовательского анализа
