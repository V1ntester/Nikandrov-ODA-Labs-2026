# ЛР №4 по ОАД. Первичный анализ признакового пространства

## Данные

В [data/audi.csv](data/audi.csv) собраны объявления о продаже подержанных автомобилей Audi на британском рынке. Единица наблюдения — объявление. В исходной таблице **10 668 строк и 9 столбцов**. Из них 8 входных признаков и одна целевая переменная — цена объявления `price` в фунтах стерлингов. [Карточка датасета на Kaggle](https://www.kaggle.com/datasets/adityadesai13/used-car-dataset-ford-and-mercedes)

## Типы и назначение признаков

| Столбец | Тип в pandas | Тип признака | Назначение |
|---|---|---|---|
| `model` | Строковый | Номинальный | Модель Audi |
| `year` | `int64` | Дискретный числовой | Год регистрации |
| `price` | `int64` | Числовой, целевой | Цена объявления, £ |
| `transmission` | Строковый | Номинальный | Тип коробки передач |
| `mileage` | `int64` | Количественный, записан в целых милях | Пробег |
| `fuelType` | Строковый | Номинальный | Тип топлива |
| `tax` | `int64` | Числовой, записан в целых фунтах | Дорожный налог, £ |
| `mpg` | `float64` | Непрерывный числовой | Топливная экономичность, миль на галлон |
| `engineSize` | `float64` | Непрерывный числовой | Рабочий объём двигателя, л |

## Проверка качества данных

- Пропусков во всех девяти столбцах и пустых категорий после удаления пробелов не обнаружено.
- У всех 10 668 значений `model` есть начальный пробел. При дальнейшей обработке его следует удалить.
- Обнаружено 103 строки, полностью совпадающие с ранее встречавшимися строками по всем полям. В таблице нет идентификатора объявления, поэтому по совпадению полей нельзя установить, относятся ли эти строки к одному объявлению.
- Нулевой объём двигателя встречается в 57 объявлениях, из них 41 бензиновое и 16 дизельных. Эти значения требуют отдельной проверки перед анализом объёма двигателя и вычислением отношений с ним в знаменателе.
- Нулевой дорожный налог встречается в 536 строках. В исходной статистике эти значения учтены как записанные числовые значения.

Статистики и частоты рассчитаны по исходным строкам, включая повторяющиеся строки и записи с нулевым объёмом двигателя.
